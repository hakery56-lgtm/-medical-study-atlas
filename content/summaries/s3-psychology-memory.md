## 1. Definition, three phases and four models

- ⭐ **Memory** = the **information-processing and cognitive ability to encode, store and retrieve information**.

### Three phases
| Phase | Meaning |
|---|---|
| **Encoding** | the **active process of putting information into memory** — sensory input is **changed into a form the system can store** |
| **Storage** | **holding encoded information until retrieval** — concerns **where it is stored, how long (duration), how much (capacity) and what kind**; **short-term or long-term**; **the way we store it affects the way we retrieve it** |
| **Retrieval** | **getting or recalling information** placed in short- or long-term storage (**remembering**); **if we cannot remember, we may be unable to retrieve it** |

### Four memory models
1. **Information Processing Approach** — memory is a process **analogous to a computer** (encodes, stores, retrieves).
2. **Parallel Distributed Processing model** — memory is **distributed across a network of interconnected units working simultaneously (in parallel)**.
3. **Levels of Processing approach** — memory depends on the **depth of mental processing** when the material is first encountered.
4. **Traditional Three-Stage model** — memory needs **three storage boxes** holding information for different lengths of time.

<div class="key-points">

**Key points**
- Memory = encode + store + retrieve.
- Encoding = put in; storage = hold (duration, capacity); retrieval = recall.
- Models: information processing (computer), parallel distributed (network), levels of processing (depth), three-stage (three boxes).

</div>

## 2. Types of memory: sensory, working and long-term

### Sensory memory
- The **first system**: information enters through the **senses**; like **a door open for a brief time**; **lasts about a second**; **separate stores for each sense**.
- **Iconic (visual) memory: < 1 second.** **Echoic (auditory) memory: about 2 seconds.**
- **No attention → forgotten; attention → transferred automatically to short-term memory.**

### Working (short-term) memory
- Holds **about 7 items (5–9 bits, 7 ± 2 chunks)** for **2–30 seconds**; duration lengthened by **rehearsal**.
- **Capacity increased by chunking** (grouping items into meaningful wholes).
- Three points: **attention transfers information in**; **it disappears unless rehearsed**; **some is transferred to permanent storage**.
- **Maintenance rehearsal** = intentionally repeating to keep it longer; **coding can be acoustic, visual or semantic**.

### Long-term memory
- **Almost unlimited capacity and duration**.
- **Encoding** = transfer from short- to long-term memory by **paying attention, rehearsing, or forming new associations**.
- **Retrieval** = the process controlling flow **from long-term to working memory**; like a **library, it must be organized**; **the better the encoding, the greater the chance of retrieval**.

| | **Sensory** | **Working (short-term)** | **Long-term** |
|---|---|---|---|
| Duration | **~1–2 s** | **2–30 s** | **unlimited** |
| Capacity | large, momentary | **7 ± 2** | **unlimited** |
| Key process | **attention** | **rehearsal, chunking** | **encoding / retrieval** |

<div class="key-points">

**Key points**
- Sensory ≈ 1 s (iconic < 1 s, echoic ≈ 2 s); attention moves it to short-term memory.
- Working memory 7 ± 2 items, 2–30 s; chunking raises capacity; rehearsal prolongs duration.
- Long-term: unlimited; encoding by attention, rehearsal, association; retrieval from long-term to working memory.

</div>

## 3. Declarative vs procedural memory

| | **Declarative (explicit)** | **Procedural (nondeclarative)** |
|---|---|---|
| Content | **facts or events** — scenes, stories, words, conversations, faces, daily events | **motor skills** (playing tennis), **some cognitive skills** (learning to read), **emotional behaviors learned by classical conditioning** (fear of spiders) |
| Awareness | **we are aware of it and can recall/retrieve it** | **we cannot recall or retrieve it** consciously |
| Subtypes | **Semantic** and **episodic** | — |

- ⭐ **Semantic memory:** **facts, concepts, words, definitions, language rules** — **most of what you learn in classes**.
- ⭐ **Episodic memory:** **specific events, personal experiences (episodes), activities** (favorite restaurants, movies, songs, habits) — **most college activities and experiences**.

### Brain areas and neurotransmitters
- **Areas:** **hippocampus, amygdala, prefrontal cortex, basal ganglia, cerebellum**.
- **Neurotransmitters:** **acetylcholine, serotonin, dopamine, norepinephrine**, some **neuropeptides**, others (**protein, DNA, RNA**).

<div class="key-points">

**Key points**
- Declarative = facts/events (semantic + episodic); procedural = skills, conditioned emotions (cannot be recalled).
- Semantic = facts and definitions (class learning); episodic = personal events (college experiences).
- Areas: hippocampus, amygdala, prefrontal cortex, basal ganglia, cerebellum; transmitters: ACh, serotonin, dopamine, NE.

</div>

Procedural (nondeclarative) memory holds motor skills (tennis), some cognitive skills (reading) and emotional behaviors learned by classical conditioning (fear of spiders), and cannot be consciously recalled.

## 4. Forgetfulness and memory-enhancement strategies

### Factors contributing to forgetfulness
1. **Age** — **age-associated memory impairment**, a **normal** mild forgetfulness (names, misplaced objects).
2. **Stress and anxiety** — impair **concentration and retrieval**; **stress hormones affect the hippocampus**.
3. **Lack of sleep** — impairs **cognitive function, concentration and retention**.
4. **Medical conditions** — **thyroid disorders, vitamin deficiencies (B12), infections, head injuries, Alzheimer's disease/dementia**.
5. **Medications and substance abuse** — drugs for **anxiety, depression, sleep disorders**; **alcohol and drugs**.

### Memory-enhancement strategies (13)
1. **Pay attention** 2. **Mnemonic devices** 3. **Chunking** 4. **Visualization** 5. **Association** (link to what you know) 6. **Practice retrieval** 7. **Spaced repetition** (not cramming) 8. **Multi-sensory techniques** 9. **Sleep well** (consolidation) 10. **Stay organized** 11. **Teach someone else** 12. **Stay mentally active** 13. **Manage stress**.

<div class="key-points">

**Key points**
- Forgetting: age (normal mild), stress/anxiety (hippocampus), sleep loss, medical conditions (thyroid, B12, infection, head injury, dementia), drugs/alcohol.
- Strategies: attention, mnemonics, chunking, visualization, association, retrieval practice, spaced repetition, multisensory, sleep, organization, teaching, mental activity, stress management.

</div>

## 5. Psychopathology of memory and communication skills

### Amnesia — partial or complete loss of memory
- Causes: **physical injuries, medical conditions, psychological trauma, certain psychiatric disorders**.
- ⭐ **Retrograde amnesia — old memories lost.**
- ⭐ **Anterograde amnesia — new memories lost.**
- **Transient global amnesia — temporary amnesia, usually lasting a few hours.**

### Other disturbances
- **Memory intrusions** — **involuntary, unwanted recall of distressing or traumatic memories**; commonly in **PTSD**.
- **Memory distortions** — **inaccuracies or alterations in recall**; commonly in **depression, anxiety disorders and schizophrenia**.

### Link with communication skills
- Memory processes affect **patient understanding, recall and adherence** to medical advice.
- Attention, repetition and meaningful organization improve retention; **stress, sleep problems and illness impair recall**.
- Clinicians should **present information clearly and in a structured way, use repetition, chunking and visual explanations, check patient recall, and adapt communication** for patients with memory difficulties, stress or illness.

<div class="key-points">

**Key points**
- Amnesia: retrograde = old lost; anterograde = new lost; transient global = a few hours.
- Intrusions = unwanted traumatic recall (PTSD); distortions = inaccurate recall (depression, anxiety, schizophrenia).
- Communication: clear structured information, repetition, chunking, visuals, check recall.

</div>

**Short-essay questions**

<details><summary>Q1. Define amnesia and its types.</summary>

**Answer:** Amnesia is partial or complete loss of memory, caused by physical injury, medical conditions, psychological trauma or psychiatric disorders. Retrograde amnesia is loss of old memories, anterograde amnesia is loss of the ability to form new memories, and transient global amnesia is a temporary form lasting usually a few hours.

**Why:** Slide "Psychopathology of memory".
</details>

<details><summary>Q2. Differentiate memory intrusions from memory distortions.</summary>

**Answer:** Intrusions are involuntary, unwanted recall of distressing or traumatic memories, commonly in PTSD; distortions are inaccuracies or alterations in recalled memory, commonly seen in depression, anxiety disorders and schizophrenia.

**Why:** Slide "Memory intrusions / distortions".

**Answer:** Because encoding, storage and retrieval determine what patients understand and remember, clinicians should present information clearly and in a structured way, use repetition, chunking and visual explanations, check the patient's recall and comprehension, and adapt communication for patients with memory difficulties, stress or illness.
